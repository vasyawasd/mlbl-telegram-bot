# MLBL Moscow Telegram Bot

Telegram-бот для мониторинга расписания матчей и цвета игровой формы в лиге МЛБЛ Москва (https://moscow.ilovebasket.ru).

## Возможности
- 🔔 **Авто-напоминание за 1 день:** бот проверяет расписание и накануне игры присылает уведомление «Завтра матч!» с залом и формой.
- 👕 **Цвет формы:** определяет форму (хозяева — ⚪️ светлая, гости — ⚫️ чёрная).
- 🔍 **Автопоиск команды:** при вводе `/set НазваниеКоманды` бот сам находит нужный дивизион среди всех лиг МЛБЛ (Элита, Претенденты, Лига Развития, Lite и др.).
- 📅 **Поиск по дате:** можно спросить `/game 15.10`, чтобы узнать игру на конкретную дату.
- 📋 **Календарь на 3 месяца:** команда `/schedule` выводит все назначенные матчи на сезон вперёд.
- 🛡 **Защита от спама:** команды `/set` и `/unset` доступны только администраторам группы; попытки обычных игроков удаляются через 1.5 секунды.

## Команды бота
- `/game` — ближайший матч
- `/game ДД.ММ` — матч на конкретную дату (например `/game 04.10`)
- `/schedule` — полное расписание матчей команды
- `/set НазваниеКоманды` — привязать группу к команде (для админов)
- `/unset` — отвязать группу (для админов)
- `/help` — справка
