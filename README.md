# MLBL Moscow Telegram Bot

Telegram-бот для мониторинга расписания матчей и цвета игровой формы в лиге МЛБЛ Москва ([moscow.ilovebasket.ru](https://moscow.ilovebasket.ru)).

## Возможности

- Авто-напоминания за 24 и 3 часа до матча.
- Определение формы: хозяева — светлая, гости — чёрная.
- Поиск команды и дивизиона по команде `/set`.
- Поиск матча по дате и календарь будущих игр.
- Администраторская защита настроек группы.
- Надёжный супервизор: один экземпляр, корректная передача сигналов дочернему процессу, ограниченный экспоненциальный перезапуск со случайным разбросом и безопасное завершение при ошибке конфигурации.

## Команды бота

- `/game` — ближайший матч.
- `/game ДД.ММ` — матч на выбранную дату, например `/game 04.10`.
- `/game НазваниеКоманды` — ближайший матч указанной команды.
- `/schedule` — полный календарь матчей команды.
- `/set НазваниеКоманды` — привязать группу к команде (только для администраторов).
- `/unset` — отвязать группу (только для администраторов).
- `/help` — справка.

## Быстрый запуск

Требуется Python 3.10+ и `pip`.

```sh
git clone <repository-url>
cd mlbl_telegram_bot
python3 -m venv .venv
. .venv/bin/activate                 # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
cp .env.example .env                 # Windows cmd: copy .env.example .env
```

Откройте `.env` в локальном редакторе и задайте токен, полученный только от [@BotFather](https://t.me/BotFather):

```dotenv
BOT_TOKEN=your-token-from-botfather
```

Запустите супервизор:

```sh
./start.sh
# or, on Windows:
python supervisor.py
```

Не запускайте `main.py` одновременно со `start.sh`/`supervisor.py`: только супервизор должен владеть жизненным циклом бота. В Termux wake lock также приобретает и освобождает только супервизор.

## Конфигурация и безопасная эксплуатация

- Не добавляйте `.env`, токен или `chats.json` в Git. Эти файлы уже исключены в `.gitignore`.
- Не передавайте токен в командной строке, логах, чатах, issue или скриншотах. При подозрении на утечку немедленно отзовите токен через @BotFather и создайте новый.
- Можно передать `BOT_TOKEN` через защищённое окружение процесса вместо `.env`.
- Супервизор завершится с кодом `2` без перезапусков, когда токен не задан или `main.py` отсутствует. Это сигнал исправить конфигурацию, а не сетевой сбой.
- При временном сбое дочернего процесса супервизор перезапускает его с ограниченной экспоненциальной задержкой и jitter. Длительный стабильный запуск сбрасывает задержку.
- Состояние групп хранится в `chats.json`. Для контейнерного запуска оно находится в постоянном Docker volume; сохраняйте его резервную копию отдельно.

## Docker Compose

1. Скопируйте пример: `cp .env.example .env`.
2. Впишите реальный `BOT_TOKEN` только в локальный `.env`.
3. Запустите: `docker compose up -d --build`.
4. Просматривайте логи без вывода токена: `docker compose logs -f bot`.
5. Остановите сервис: `docker compose down`.

Compose передаёт `.env` контейнеру как окружение и хранит `chats.json`, PID и lock-файлы в именованном volume `bot-data`. Не публикуйте `.env` и не включайте его в образ: `.dockerignore` исключает его из build context. Контейнер выполняется непривилегированным пользователем.

## Проверка

```sh
python -m py_compile supervisor.py main.py test_supervisor.py
BOT_TOKEN=test-token python -m unittest -v
```

В CI выполняются компиляция, unit-тесты и сборка Docker-образа. Тесты не требуют настоящего Telegram-токена.
